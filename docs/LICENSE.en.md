# What the license allows

[Español](LICENCIA.es.md) · **English** · [简体中文](LICENSE.zh-CN.md)

TableroBlanco uses a project-specific license: **TableroBlanco No-Sale License 1.0**. The authoritative English text is in [LICENSE](../LICENSE).

| Activity | Allowed |
| --- | --- |
| Personal use | Yes |
| Internal use within a business | Yes |
| Studying and modifying the code | Yes |
| Sharing copies free of charge | Yes |
| Charging for installation, training or support services | Yes |
| Charging for customization, maintenance or consulting | Yes |
| Offering a paid hosted service that uses the app | Yes |
| Selling the program or software licenses for it | No |
| Selling a modified version containing TableroBlanco code | No |
| Charging to download or receive a copy of the program | No |

When sharing a copy, keep the license and copyright notices. Modified versions must identify that they have been modified. Charging for an actual service is allowed; simply renaming a software sale price as a “service fee” does not remove the restriction. A paid hosted service must not transfer a paid copy or paid software license to the customer.

The restriction applies to this project's own code and documentation, not to Excalidraw, Electron, React, fonts or other components with their own licenses. It is not an OSI-approved open-source license because it restricts sales. The source is available to study, modify and share under these conditions.

This license applies from the first public release, version 1.2.1. Earlier local packages were distributed under MIT and retain their original permissions. The new license cannot revoke those permissions retroactively.

This summary is provided for readability; in case of a difference, the English text of [LICENSE](../LICENSE) prevails. The license is specific to this project and is not presented as a legally certified text or as having been reviewed by an external legal adviser.
