# Qué permite la licencia

TableroBlanco usa una licencia propia: **TableroBlanco No-Sale License 1.0**. El texto vinculante está en [LICENSE](../LICENSE).

| Actividad | Permitida |
| --- | --- |
| Usar la aplicación personalmente | Sí |
| Usarla internamente en una empresa | Sí |
| Estudiar y modificar el código | Sí |
| Compartir copias gratuitamente | Sí |
| Cobrar por instalación, capacitación o soporte | Sí |
| Cobrar por personalización, mantenimiento o consultoría | Sí |
| Ofrecer un servicio de alojamiento de pago que utiliza la aplicación | Sí |
| Vender el programa o sus licencias | No |
| Vender una versión modificada que contiene código de TableroBlanco | No |
| Cobrar por descargar o recibir una copia del programa | No |

Al compartir una copia se deben conservar la licencia y los avisos de derechos de autor. Las versiones modificadas deben indicar que fueron modificadas. Cobrar realmente por un servicio está permitido; cambiar el nombre de un precio de venta a “servicio” no elimina la restricción.

La restricción se aplica al código propio de este proyecto, no a Excalidraw, Electron, React, las fuentes u otros componentes que tienen sus propias licencias. No es una licencia de código abierto aprobada por la OSI, porque restringe la venta. Es código disponible para estudiar, modificar y compartir bajo estas condiciones.

Esta licencia se utiliza desde la primera publicación pública, versión 1.2.1. Los paquetes locales anteriores se entregaron con MIT y conservan sus permisos originales. La nueva licencia no puede quitar retroactivamente esos permisos.

Este resumen facilita la lectura; en caso de diferencia prevalece LICENSE. La licencia es específica del proyecto y no se presenta como un texto jurídico certificado o revisado por un asesor externo.
