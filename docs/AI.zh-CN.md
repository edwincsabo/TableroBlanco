# 使用 AI 总结并提出任务

[Español](IA.es.md) · [English](AI.en.md) · **简体中文**

适用于 Windows 版 TableroBlanco 1.4.0。助手可总结所选文字、提出任务并列出待解问题。AI 为可选功能，默认停用。无需配置服务提供商，仍可使用绘图、保存、模板等工具。

## 配置服务提供商

1. 在白板库中打开**设置 → 可选人工智能**，或在编辑器中打开**总结并提出任务 → 配置 AI**。
2. 选择 **OpenAI**、**OpenRouter** 或 **Claude (Anthropic)**。
3. 输入您的账户可用、支持结构化 JSON 响应的文本模型标识符。初始值是可编辑的示例，不保证您的账户有访问权限，分别为 `gpt-4.1-mini`、`openai/gpt-4.1-mini` 和 `claude-haiku-5-5`。
4. 粘贴服务提供商的 API 密钥，勾选**启用可选 AI**，然后点击**保存 AI 设置**。

保存设置不会发送请求或向服务提供商验证密钥。进行分析时才会检查身份验证、模型访问权限和其他权限。您需要 API 访问权限及服务提供商要求的余额或计费设置。应用不提供使用额度，也不保证聊天订阅包含 API 使用权限。

每个服务提供商可以分别保存模型和密钥，仅使用当前启用的服务提供商。切换后需要保存设置，并在发送内容前重新核对预览。

## 创建建议

1. 选择需要分析的便利贴、含文字的形状或文字对象。选择便利贴形状时，会包含其关联文字。
2. 点击底部工具栏中的**总结并提出任务**。
3. 核对显示的文字、服务提供商和模型。应用不会自动添加白板的其他内容。
4. 点击**发送并分析**。应用会请求使用当前界面语言输出：西班牙语、英语或简体中文。
5. 核对并编辑摘要、任务和问题。可以取消勾选不需要的任务。
6. 点击**插入为新卡片**，或**放弃建议**。

插入的卡片是可编辑的画布对象，原始便利贴会保留。只有选择插入后，响应内容才会更改白板。应用不会执行任务、分配人员或向第三方发送消息。

任务会区分“便利贴中提及的行动”和“AI 建议”，并引用预览中的临时来源文字编号。这有助于核对，但不能证明理解正确。请特别检查人员、日期和承诺：AI 可能出错，也可能提出您尚未决定的事项。

## 发送和保存哪些内容

请求包含所选文字、`n1` 等临时编号、摘要指令和输出结构。不会自动发送白板名称、缩略图、图片、PDF、绘图、历史记录、文件路径或未选择的文字。不进行文字识别，也不访问便利贴中的链接。

密钥仅用于请求身份验证，不作为模型输入。请求从主进程发送到固定的服务提供商端点。不接受自定义服务器或身份验证重定向。

密钥使用 Electron safeStorage 和针对当前用户的 Windows 保护进行加密，然后保存到应用配置目录中的 `ai-settings.json`，位于白板库、导出文件和白板备份之外。密钥不会再次显示，需要在其他电脑上单独配置。此加密不能防止以同一 Windows 用户身份运行的恶意应用访问密钥。

助手不会创建本地查询历史。插入后，结果成为白板内容，按正常方式保存和备份；如果配置了同步文件夹，也会写入该文件夹。已发送内容的处理和保留由服务提供商决定。OpenRouter 可能将请求路由至其他模型提供商。OpenAI 请求使用 `store: false`，但这并不保证零保留。

## 限制与错误

- 每次选择 1 至 60 个文字对象，每个最多 6,000 个字符，总计最多 20,000 个字符。超限时会拒绝请求，不会悄悄截短内容。
- 最多 12 项任务和八个问题。响应会在显示前进行验证。
- 请求超时时间为 60 秒。可以取消分析或关闭助手以请求取消。
- 每次分析仅发送一次请求，不自动重试。取消操作不能保证服务提供商停止处理或停止对已收到的请求计费。

密钥无效、模型不可用或不兼容、使用限制、网络错误或无效响应都会显示提示，不会插入内容。保存设置并不保证该服务提供商的所有模型都兼容。

## 停用 AI 或删除密钥

点击**停用 AI**可保留加密密钥，同时禁止新的分析。点击**删除已保存的密钥**可从本机移除该服务提供商的凭据；如果它是当前启用的服务提供商，AI 会停用。在此删除不会撤销服务提供商账户中的密钥，如有需要，请同时在该账户中撤销。
