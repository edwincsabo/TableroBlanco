# 同步文件夹与恢复

[Español](SINCRONIZACION.md) · [English](SYNC.en.md) · **简体中文**

适用于 Windows 版 TableroBlanco 1.3.0。可以将白板库保存在由 OneDrive、Google Drive 或其他桌面客户端同步的文件夹中。TableroBlanco 读写本地文件，由服务提供商将其传输至云端。无需在 TableroBlanco 内登录账户。

## 设置文件夹

1. 安装所选同步客户端，并使用服务提供商的账户完成配置。
2. 创建专用文件夹，例如 `OneDrive\TableroBlanco` 或 Google Drive 中的文件夹。
3. 将文件夹设为可离线使用。OneDrive 可以使用“始终保留在此设备上”；Google Drive 可以使用镜像模式，或将文件夹设为可离线使用。
4. 在 TableroBlanco 白板库中打开**设置 → 白板位置 → 更改文件夹**。
5. 选择文件夹，核对路径和白板数量，然后点击**复制并使用文件夹**。

启用新位置前，应用会创建本地备份、复制白板及其历史记录，并验证内容。目标文件夹中已有的白板会保留。如果标识符相同但内容不同，传入的白板将使用新标识符保存，名称末尾添加“冲突副本”。

原始文件不会被删除。更改后，新保存的内容只会写入新位置；原始文件夹保留迁移时的副本。不要选择当前白板库内部的文件夹，也不要选择包含当前白板库的父文件夹。本地恢复文件夹也不能作为目标位置。

## 在另一台电脑上继续使用

在另一台电脑上安装 TableroBlanco 和同步客户端。等待白板库下载完成，将其设为可离线使用，然后在设置中选择该文件夹。该电脑上的本地白板会添加到目标白板库中，两边的内容都会保留。

切换电脑前，请完成编辑，并在服务提供商的客户端中确认同步已完成。“已保存到文件夹”仅表示本地写入成功，并不表示上传完成。TableroBlanco 不显示传输状态或云存储配额。

## 外部更改与冲突

应用约每三秒检查一次文件变化，并在窗口重新获得焦点时检查。白板库会自动刷新。外部内容不会替换已打开的画布；如果其文件发生变化或被删除，应用会显示提示。

保存过期版本时，本地更改会另存为独立白板。文件夹中收到的版本会保留，可以在白板库中分别打开两个版本。应用不支持自动合并对象或实时协作。同步服务生成的、文件名不同的冲突副本也会显示为独立白板。

这些检查有助于降低覆盖风险，但不是分布式锁，也不能保证解决客户端之间所有的并发情况。同步依赖服务提供商和网络连接。请避免在两台电脑上同时编辑同一块白板，并保留独立备份。

## 文件夹不可用或文件无法读取

如果配置的文件夹消失，应用会提示，不会悄悄切换到空白白板库。请重新连接驱动器或同步客户端，等待文件夹恢复可用。无法读取的文件会保留并显示在提示中，不会自动删除或替换。

保存失败时，编辑器会显示错误，您仍可导出可编辑副本。关闭窗口时，如果待保存的更改无法写入，窗口会保持打开。更改文件夹前，请先重新连接不可用的原始位置，或恢复您的副本。

## 本地恢复与独立备份

打开**设置 → 打开本地恢复文件夹**。该位置保留在 Windows 用户配置文件中，位于所选白板库之外：

- `migraciones`：更改文件夹前验证过的白板及历史记录副本。`origen.txt` 记录原始路径。
- `estados`：按白板和位置保存最近一次提交的状态及其前一个状态。这些文件不是完整历史记录，也不是云备份。

恢复单块白板时，选择**导入**并打开相应的 `.json` 文件；它会作为使用新标识符的副本打开。恢复整个白板库时，可以导入其中的白板，或恢复通过**创建完整备份**生成的 JSON 备份。导出的完整备份不包含历史快照。

同步也可能传播删除操作。请保留独立于同步文件的备份，尤其是在更新应用、切换账户或整理文件夹之前。

## 限制与验证

此功能使用演示文件夹测试，涵盖模拟其他电脑的文件更改、冲突、重启和断开连接。测试未使用用户的个人账户，也未认证所有服务提供商的真实云传输。同步客户端必须支持正常的文件读写，并具有足够的存储空间和权限。
